# open-carpool 로드맵

작성 2026-10-24. 근거: [research/market-research-2026-10.md](research/market-research-2026-10.md), [research/operations-workflow.md](research/operations-workflow.md). [S#]는 리서치 문서의 출처 번호다.

## 제품 정의

open-carpool은 이미 아는 사람끼리 모인 단체(회사, 대학, 동호회, 학부모 모임)가 **고정 카풀 크루를 운영하고 기록하는 도구**다. 모르는 사람을 이어 주는 매칭 앱은 만들지 않는다.

- **포지션**: 단톡방(카카오톡, LINE, WhatsApp)을 대체하지 않는다. 채팅 안에서 공유 링크로 쓰는 **간사(champion)의 명단·순번·기록 도구**다. 핵심 가치는 간사의 관리 부담(명단 관리, 교대 후 순번 재계산, 단체에 제출할 기록)을 덜어 주는 것이다.
- **1차 타깃**:
  - 동호회, 학부모, 소규모 직장 크루: 무료 셀프서비스
  - 공공기관, 국립대, 산업단지: 부제나 주차난이 생기면 바로 켜는 '부제 모드'와 기관용 리포트
- **사업 현실**: 소규모 모임은 돈을 거의 내지 않는다. 비용을 내는 쪽은 언제나 기관이다[S55]. 그래서 무료 셀프서비스로 퍼뜨리고, 선택형 기관용 리포트·내보내기 플랜으로 수익을 낸다.
- **해외**: 영어 셀프서비스(미국 중심)를 먼저 한다. 일본과 스페인은 관찰 대상이다.

## 결정 사항

| 항목 | 결정 | 근거 |
|---|---|---|
| 앱 형태 | **v1은 실시간 위치 기능 없이 PWA로 낸다.** 앱 스토어 배포, 안정적인 iOS 푸시, 실시간 위치가 필요해지면 그때 Capacitor로 감싼다(React 코드 재사용). 감쌀 때는 Guideline 4.2(최소 기능) 거절 리스크를 먼저 확인한다. React Native나 Flutter로 다시 짜지 않는다 | iOS PWA는 백그라운드 위치를 쓸 수 없다[S58]. 웹 푸시는 홈 화면에 설치한 경우에만 된다[S44]. 국내 20대의 60%가 iPhone이라 홈 화면 설치 안내가 필수다 |
| 지도 | 국내 **네이버**(지도, 지오코딩), 해외 **Google**(지도, 지오코딩, 경로). `MapProvider` 인터페이스 뒤에서 **지역별로 지도·지오코딩·경로 전체를 함께 바꾼다**. 한 화면에 두 제공자를 섞지 않는다. Google 결과는 좌표 대신 place ID로 저장한다. 길안내는 네이버, 카카오, TMAP, Google 지도 앱으로 넘긴다(딥링크). 거리는 크루마다 한 번만 계산한다 | Google은 한국에서 운전 경로를 제공하지 않는다(2026-10 기준)[S35][S38]. 네이버는 국내 지도만 제공한다[S41]. Google 약관 §3.2.3[S37] |
| 로그인 | Firebase Auth로 **Google**, **카카오**(OIDC 또는 custom token), 이메일 링크를 지원한다. App Store에 낼 때 **Sign in with Apple**을 추가한다. 카카오톡 인앱 브라우저에서 열리면 외부 브라우저로 넘긴다 | 카카오톡 인앱 브라우저에서는 Google 로그인이 403으로 막힌다[S42]. Apple 가이드라인 4.8[S43] |
| 다국어 | **i18next + react-i18next**. ko, en으로 시작한다 | 생태계가 가장 크다(주간 다운로드 1,520만 건)[S46] |
| 범용화 | 충남대 전용 요소를 모두 제거한다. 2부제 규칙은 그룹 정책 플러그인으로 옮긴다 | 사용자 결정 |
| 모임 | 그룹 만들기, 초대 링크·QR·코드, 이메일 도메인 자동 승인, 역할(owner, admin, captain, member) | Mobicoop 커뮤니티 모델[S34] |
| 비용 | **국가별 기능 플래그.** 한국은 **돈이 오가지 않는 교대 운전만** 지원한다. 교대 운전이 곧 비용 분담이고, 금액 기능과 운전자 배정을 함께 두면 알선 위험이 있다. 실비 분담이 합법인 국가(미국, 일본, EU 등)에서만 금액 계산을 켜고, 금액은 사용자가 정한다. 앱 안에서는 결제하지 않는다 | 제81조, 대법원 97도1463, 국토부 유권해석[S1][S2][S4], CJEU C-434/15[S52] |
| 위치 | v1에는 실시간 추적을 넣지 않는다. 나중에 넣으면 출시 전에 위치정보법 신고를 하고, 위치를 공유할 때마다 통지한다 | 위치정보법 제9조, 제19조[S5] |
| 출시 모델(권고) | **오픈코어.** AGPL-3.0 코어 레포는 누구나 직접 설치해 쓸 수 있다. 공식 호스팅 앱은 소규모 그룹에 무료다. 유료 기관 플랜에는 SSO와 도메인 인증, 리포트, CSV·ESG 내보내기, 부제 모드를 넣는다. 오픈소스 공개와 앱 출시는 둘 중 하나를 고르는 문제가 아니고 함께 할 수 있다 | 오픈소스 카풀 중 사업이 되는 곳은 Mobicoop 하나이고, 오픈코어로 전환했다[S33]. 업체가 서비스를 종료한 사례(TwoGo)[S29]가 있어서 데이터 내보내기가 판매 포인트가 된다 |

## 단계

### Phase 0: 정리와 보안 (1-2주)
- [ ] `firestore.rules`를 강화한다. 지금은 users, routes, rides를 누구나 update할 수 있고, isAdmin을 클라이언트에서 판정한다
- [ ] 자체 SHA-256 로그인을 Firebase Auth로 바꾼다. 교번, 이름, 학과만으로 비밀번호를 재설정할 수 있는 문제도 함께 없앤다
- [ ] 운영 DB를 직접 건드리는 `scripts/*`를 dry-run 기본값으로 바꾸고, `--project`와 `--confirm`을 필수로 한다
- [ ] 레포를 정리한다: `replace.ts`, 루트의 중복 문서와 PNG, AI Studio README, `GEMINI_API_KEY` define, `_cors.ts`의 startsWith 검사
- [ ] `package.json`의 name을 바꾸고, `test` 스크립트를 추가하고, `tsconfig`의 include를 정리한다
- 완료 기준: 에뮬레이터 규칙 테스트, `npm run lint`, `npm test`가 모두 통과한다

### Phase 1: 범용화와 구조 개편 (2-4주)
- [ ] 폴더 구조를 `src/app`, `src/features/{auth,groups,crews,trips,ledger,admin,profile,map}`, `src/shared`, `src/policies`, `api/`, `functions/`, `tests/`로 바꾼다
- [ ] 데이터 구조를 `groups/{groupId}/{members,crews,trips,ledger}`로 바꾼다
- [ ] 충남대 요소를 제거한다: TopAppBar, `campusBuildings.ts`, `CampusBuildingSelector`, 권역 목록, 하드코딩된 캠퍼스 좌표 4곳, manifest, metadata, index.html, 테스트와 시드 데이터
- [ ] `vehicleUtils`의 2부제 규칙을 `policies/plate-rotation`으로 옮긴다
- [ ] `MapProvider` 인터페이스를 만들고 i18next를 도입한다(ko, en)
- [ ] `cnu-*` localStorage로 데이터를 이중 저장하는 구조를 없앤다
- 완료 기준: 충남대 관련 grep 결과가 0건이고, 그룹 두 개의 데이터가 서로 격리된다

### Phase 2: 운영 MVP (4-6주)
- [ ] 그룹 만들기와 초대(링크, QR, 코드, 도메인 자동 승인), Google·카카오 로그인, 카카오톡 인앱 브라우저 탈출
- [ ] 프로필(대략적인 지역, 평소 일정 필수, 좌석 수)
- [ ] 크루 제안과 수락, 킥오프 체크리스트, captain과 backup driver
- [ ] 주간 템플릿, 전날 마감, Fagin-Williams 자동 배정
- [ ] **날짜별 빠지기·교대 요청, '운전자 필요' 알림, 대체 이동수단 안내**. 크루가 깨지는 1순위 원인이 불규칙한 일정이다[S57]
- [ ] 원탭 운행 완료 체크, 운행 기록, 공정 점수 장부
- [ ] **카카오톡 공유 카드**(크루 일정과 교대 요청을 링크로 보내기)
- [ ] 국가별 비용 플래그(한국은 교대 운전만, 그 외는 실비)
- [ ] 관리자 대시보드와 CSV 내보내기
- [ ] 웹 푸시(홈 화면 설치 안내)와 전날 저녁 요약 알림
- 완료 기준: 실제 그룹 1곳(크루 3개 이상)에서 2주간 운영하고, 일정 확정률과 운행 기록률을 측정한다

### Phase 3: 출시 (2-3주)
- [ ] 오픈소스로 공개하고(AGPL-3.0 확정) self-host 문서를 쓴다
- [ ] 개인정보처리방침과 이용약관을 준비한다
- [ ] 부제 모드: 홀짝 차량끼리 짝짓고, 부제일에 크루를 자동 편성한다
- [ ] 크루 이탈 감지: 출석이 줄면 알리고 대체 멤버를 제안한다
- [ ] 이벤트 카풀 보드
- [ ] (필요할 때) Capacitor 래핑, Sign in with Apple, 스토어 등록
- 완료 기준: 국내 단체 3곳 이상이 사용한다

### Phase 4: 해외 (영어 셀프서비스 먼저, 일본·스페인은 관찰)
- [ ] 영어 번역 완성, Google 지도 스택, 실비 프리셋, 앱 스토어 Pro(IAP) 검토
- [ ] 일본: LINE 공유와 로그인은 소비자 모임용으로만 검토한다. 회사 규정(マイカー通勤規程)이 동승을 금지하는 경우가 많아 B2B는 보류한다[S60]
- [ ] 스페인: Ley 9/2025 이동계획 컨설팅사와 파트너 채널로만 검토한다[S51]
- [ ] 유료 기관 플랜(SSO, 리포트, 내보내기)

## 리스크
- 실제 경쟁자는 앱이 아니라 단톡방과 통근버스다. 2026년 2부제 수요는 앱 없이 자발적 카풀과 통근버스(이용 40% 증가)가 흡수했다[S59].
- 소규모 모임은 돈을 거의 내지 않는다. Carpool-Kids가 무료 + Pro 모델로 이미 자리를 잡았다[S56].
- Google의 한국 길안내는 1-2년 안에 열릴 수 있다. 경로 기능은 어댑터 뒤에 둔다.
