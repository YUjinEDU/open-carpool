# 개인정보처리방침 (템플릿)

> 이 문서는 open-carpool을 운영하는 단체나 사업자가 고쳐 쓸 수 있는 **템플릿**입니다. 법률 자문이 아니므로, 서비스를 공개하기 전에 실제 운영 방식에 맞게 고치고 검토를 받으세요. `[대괄호]` 부분은 운영자가 채웁니다.

[운영자명](이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

## 1. 처리하는 개인정보 항목
| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 계정 | 이름(표시명), 이메일, 프로필 사진 URL, 로그인 제공자(Google·카카오·이메일 링크) 식별자 | 로그인 시 제공자로부터 받음 |
| 그룹 활동 | 소속 그룹, 역할, 운전 가능 여부, 좌석 수, 차량 번호 끝자리(부제 정책을 쓰는 그룹만), 주간 출퇴근 일정 | 이용자가 직접 입력 |
| 대략적 위치 | 출발 지역 이름과 소수점 3자리로 반올림한 좌표(약 100m 단위) | 이용자가 주소 검색으로 직접 입력 |
| 운행 기록 | 운행 날짜, 운전자, 탑승자, 불참 여부, 완료 처리 시각 | 서비스 이용 중 생성 |

open-carpool은 **실시간 위치를 수집하거나 다른 이용자에게 실시간으로 공유하지 않습니다.** 나중에 실시간 위치 기능을 넣는다면, 운영자는 출시 전에 「위치정보의 보호 및 이용 등에 관한 법률」 제9조에 따른 위치기반서비스사업 신고를 하고 이 방침을 개정합니다.

## 2. 처리 목적
- 그룹 가입 확인과 구성원 관리
- 고정 카풀 크루 구성, 운전 순번 배정, 운행 기록과 공정성 장부 관리
- 그룹 관리자용 참여 현황 통계와 CSV 내보내기
- 부정 이용 방지와 서비스 안정성 확보

## 3. 보유 기간
- 계정 정보는 회원 탈퇴 시까지 보유합니다.
- 그룹 활동 정보와 운행 기록은 그룹에서 나가거나 그룹이 삭제될 때까지 보유합니다. 다만 그룹 관리자가 이미 내보낸 CSV 파일은 해당 그룹이 관리합니다.
- 관계 법령에서 보존을 요구하면 그 기간 동안 보관합니다.

## 4. 제3자 제공
운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 같은 그룹의 구성원에게는 그룹 운영에 필요한 정보(표시명, 운전 여부, 일정, 대략적 지역, 운행 기록)만 보입니다.

## 5. 처리 위탁과 국외 이전
| 수탁자 | 위탁 업무 | 이전 국가 | 항목 |
|---|---|---|---|
| Google LLC (Firebase) | 인증, 데이터 저장 | [리전, 예: 대한민국 서울(asia-northeast3) 또는 미국] | 1항의 전 항목 |
| [호스팅 업체, 예: Vercel Inc.] | 웹 앱 배포, 지도 API 중계 | [국가] | 접속 기록, 주소 검색어 |
| NAVER Cloud / Google Maps Platform | 주소 검색(지오코딩) | 대한민국 / 미국 | 주소 검색어 |

국외로 이전하는 경우 「개인정보 보호법」 제28조의8에 따라 이전 국가, 시기와 방법, 보유 기간을 이 방침으로 알립니다.

## 6. 이용자의 권리
이용자는 언제든 자신의 개인정보를 조회·수정·삭제하거나 처리 정지를 요구할 수 있습니다. 앱의 프로필 화면에서 직접 하거나 [연락처]로 요청하면 됩니다.

## 7. 안전성 확보 조치
- 인증은 Firebase Authentication으로 처리하며, 서비스는 비밀번호를 저장하지 않습니다.
- 데이터 접근은 Firestore 보안 규칙으로 제한합니다. 같은 그룹 구성원만 그룹 데이터를 읽을 수 있고, 본인 계정 정보는 본인만 읽을 수 있습니다.
- 전송 구간은 HTTPS로 암호화합니다.
